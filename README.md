En este laboratorio se nos reto ( en el mejor sentido de la palabra) a realizar un front que consumiera los endpoint
desarrollados durante la clase magistral.

En la carpeta UdeBank-frontend se encuentra el front, se desarrollo con react y usando axios para manejar las llamadas al back,
adicional para los estilos y desarrollo de los componenetes se escogió bootstrap. 

En la carpeta lab1arq se encuentran los endpoints, entidades y clases pertenecientes al back. Este se desarrollo en las 2 sesiones
virtuales que corresponden a este laboratorio.
